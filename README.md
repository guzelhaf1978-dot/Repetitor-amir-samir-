# Репетитор — Амир и Самир (полностью бесплатная версия)

Статическая версия без Node.js, платного сервера и API. Подходит для GitHub Pages.

## Что есть
- Два независимых профиля: Амир и Самир.
- Регистрации ученикам не требуется.
- Вход по имени + PIN.
- Каждый сразу попадает в свой кабинет.
- Оценки, прогресс, ошибки и сильные стороны сохраняются в браузере конкретного телефона.
- Работает офлайн после первого открытия.
- Можно добавить на экран iPhone как веб-приложение.
- Проверка специально показывает только «Правильно» / «Неправильно» и подсказку без готового ответа.

## Важно про бесплатность
GitHub Pages бесплатно публикует статические сайты. Данные этой версии хранятся локально в браузере, поэтому они не синхронизируются между разными телефонами. Для синхронизации между устройствами понадобится облачная база (например, бесплатный тариф Supabase) и отдельная настройка.

## Публикация
1. Создайте бесплатный аккаунт GitHub.
2. Создайте новый публичный репозиторий, например `repetitor-amir-samir`.
3. Загрузите содержимое этой папки в корень репозитория.
4. GitHub → Settings → Pages → Deploy from branch → `main` → `/root`.
5. Сохраните. Через некоторое время GitHub выдаст адрес вида `https://ВАШ-ЛОГИН.github.io/repetitor-amir-samir/`.

GitHub Pages ищет `index.html` и публикует статические HTML/CSS/JS-файлы.
