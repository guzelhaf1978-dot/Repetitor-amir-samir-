# Пошагово с iPhone

1. Откройте GitHub в Safari и войдите в свой бесплатный аккаунт.
2. Создайте новый **Public repository** с именем `repetitor-amir-samir`.
3. Откройте репозиторий → Add file → Upload files.
4. Загрузите все файлы из этого ZIP в корень репозитория (не сам ZIP).
5. Нажмите Commit changes.
6. Откройте Settings → Pages.
7. В разделе Build and deployment выберите Source: Deploy from a branch.
8. Branch: `main`, папка: `/ (root)`.
9. Нажмите Save.
10. Подождите публикации и откройте появившуюся ссылку.

На iPhone: Safari → Поделиться → На экран «Домой».
